# 固定双动量候选实验

本模块只做本地离线研究，不连接账户或交易计划入口。2023—2024年已在此前研究中被查看，所以比较结果只能称为历史探索，不能称为新的独立样本外收益提升。2025年起封存段不会进入本模块计算。

运行前固定的候选规则：4只预登记ETF，过去126个交易日的含分红收益，需127个收盘观察；仅取正动量前2只，每只35%，只有1只时35%，没有时现金。同分按代码升序，缺价或历史不足不入选，不前向填充。每20个交易日收盘复核，次一交易日开盘由现有份额账本模拟成交。参数不因本次结果调整，不做网格搜索。

对照包括每20日调仓的70%等权组合、每5日检查的70%等权容差组合（单票2.5个百分点、总仓5个百分点）。主窗完全沿用此前454交易日与容差对照的91个检查日期，并逐项核对旧报告；不一致即失败。回顾窗使用共同127个观察的暖启动，因而不覆盖2015最早阶段，所有策略共享日历。1万和10万元均为虚拟测试本金，分别运行正常费用和双倍摩擦。

```bash
cd research_v1
.venv/bin/python -m quant_research.momentum_study \
  --snapshot artifacts/market-etf-verified-20261108 \
  --out artifacts/momentum-study-new-run
```

输出目录必须不存在。输入先校验完整文件SHA256与行数，然后只物化截至2024-12-31的记录，重新执行ETF数据审计。`protocol.json`在模拟前记录参数、源码和快照哈希、UTC冻结时间及Python/NumPy/Pandas/DuckDB版本，`source/`保存对应源码字节，运行期间源文件变化则失败。失败保存`failure.json`，不覆盖旧产物。完成后产生`report.json`、`report.md`、`daily.csv`、`orders.csv`、`decisions.csv`；配对区块重采样使用20/40/60日、2000条历史情景。

候选历史筛选要求主窗4个本金/费用场景的净收益均严格超过两条对照，最大回撤均不超过15%。即使通过，也只是进入进一步验证的条件；独立前向观察仍为pending。现金收益为0，日线开盘和滑点是执行近似。历史供应商快照事后采集，缺完整历史`known_at`及修订证据；因果处理公司行动不等于证明供应商从未事后修订历史。区块重采样不是未来收益概率。

趋势研究思路参考作者一手论文 [Time Series Momentum](https://www.aqr.com/Insights/Research/Journal-Article/Time-Series-Momentum)。论文资产范围和12个月参数与本实验不同，本实验不属于论文复现，也不将论文视为本策略在A股ETF有效的证据。

撤销本次实现只需移除本说明、`quant_research/momentum_study.py`和`tests/test_momentum_study.py`，无需改动原有策略、账本或数据。保留实验目录可供审计。
